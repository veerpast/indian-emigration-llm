# Security and responsible disclosure

Do not commit Reddit credentials, Google Drive tokens, Hugging Face tokens,
private model URLs, or unreviewed personal data. Use `.env` locally and Colab's
secret manager for notebook credentials.

To report a security or privacy concern, open a private GitHub security advisory
for the repository owner. For dataset removal requests, contact the repository
owner and identify the relevant source/item ID; do not post personal data in a
public issue.
